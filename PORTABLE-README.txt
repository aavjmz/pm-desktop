项目里程碑指挥台 — Windows 绿色版
=================================

使用方法
--------
把整个文件夹解压到任意有写权限的位置（桌面、D 盘、U 盘都行），
双击「项目里程碑指挥台.exe」即可。

不需要安装，不写注册表，不需要管理员权限。

发布物分两个包
--------------
  程序包           主程序 + 数据目录，几 MB，每次更新都发这个
  WebView2运行时包 浏览器内核，约 250 MB，首次部署时下载一次即可

首次部署：两个包解压到同一个位置，会自动合并成一个文件夹。
以后升级：只下载程序包，覆盖解压即可，data\ 里的数据不受影响。
（没有 webview2\ 时程序会改用系统自带的运行时；公司管控机器上
  可能没有，所以建议保留 webview2\ 文件夹。）

文件夹里有什么
--------------
  项目里程碑指挥台.exe   主程序
  webview2\              浏览器内核（来自运行时包），别删
  data\                  你的数据
  data\backups\          每次保存自动留的历史版本（最近 10 个）

换电脑 / 备份
-------------
整个文件夹拷走就行，数据跟着走。
只想备份数据的话，拷 data\ 这一个目录即可。

注意事项
--------
* 不要放在 C:\Program Files 下。那里普通账户不能写，
  程序会把数据改存到 %APPDATA%，就失去"拷走即用"的意义了。
  （真发生时，程序顶部会显示实际的数据目录。）
* 同一份数据目录不要同时开两个程序窗口。程序本身会阻止重复启动，
  但如果把文件夹放在共享盘上被两台机器同时打开，仍可能互相覆盖。
* 杀毒软件偶尔会对没有数字签名的新 exe 报警，加信任即可。

数据出问题了怎么办
------------------
data\backups\ 里是历史版本，文件名形如
  pm_dashboard_v2.1760000000000.json
数字越大越新。把想恢复的那个复制成 data\pm_dashboard_v2.json
（先把当前的那份改个名留着），重启程序即可。
